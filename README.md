PAK National Career Gateway 2026: A Real-World Job Portal
Why I Built This??
Finding a job in Pakistan is often difficult because candidates have to search through many different websites. I developed the National Career Gateway 2026 to solve this problem by providing a centralized, "Single-Window" solution. This is a reality-based project in running mode—every link is authentic, verified, and updated for the year 2026.

Project Authenticity & Impact
100% Verified Opportunities: Unlike sample projects, every button on this portal leads to an active, official 2026 recruitment page.

Job Focused: Candidates can instantly find vacancies that match their degrees and skill levels, from entry-level to professional grades.

Current & Operational: All 9 portals, including NADRA and the Pak Army, are in active mode for the new year 2026.

Technical Features (My Code Logic)
1. Dynamic User Experience (JavaScript)
I used a clean, efficient JavaScript function called updatePortal() to handle all navigation:

Instant Background & Content Switching: When you click different department buttons, the background image, department name, and description update instantly without reloading the page.

Live Link Routing: Clicking the "PROCEED TO APPLY" button dynamically routes you to the official recruitment website of the selected department.

User Feedback: I implemented logic to manage the 'active' state of buttons, so users always know which department they are currently exploring.

2. Modern Professional Interface (HTML & CSS)
Glassmorphism UI: I designed the information hub using a .glass-card class for a premium, semi-transparent look.

Visual Readability: I applied a dark linear gradient over background images to ensure high text contrast and a corporate feel.

How to Run the Project
To experience the full functionality of this portal, follow these steps in VS Code:

Locate the index.html file in the Explorer sidebar.

Right-click on index.html.

Select "Open with Live Server" from the context menu.

Once the browser opens, click on different department buttons (e.g., PPHI SINDH, SINDH POLICE) to see the background and content change dynamically.

Featured 2026 Departments
My portal provides direct access to these authentic career gateways:

Federal Level: NADRA, Pak Army, Pak Navy, and Federal (NJP).

Provincial & Special Units: PPHI Sindh, Sindh Police, Sindh Forest, SSGC Jobs, and Sindh Jobs (SJP).
